# 🚀 GenerateX

**Generate smarter. Personalize faster. Deliver instantly.**

GenerateX is a modern document automation platform that transforms reusable templates into personalized, editable documents in seconds. Whether you're generating certificates for an event or creating customized documents in bulk, GenerateX eliminates repetitive manual work through template-based automation.

---

## ✨ Features

- 📄 Upload editable certificate templates
- ✏️ Replace placeholders dynamically (e.g. `{{NAME}}`, `{{DATE}}`, `{{EVENT}}`)
- 📥 Generate fully editable PowerPoint (`.pptx`) certificates
- 📊 Bulk generation using Excel/CSV files
- 📦 Download individual certificates or a ZIP archive
- ⚡ Fast, lightweight, and easy to use
